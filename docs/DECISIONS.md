# sPaste: decisions

Single source of truth for choices that shape the code. Newest at the bottom. Each entry: date, decision, why, what it rules out. Change a decision by adding a new entry that supersedes the old one, never by editing history.

## 2026-10-30 Build sPaste instead of waiting on Maccy

Why: Maccy covers most of the need, and its type filter is on the way (maintainer agreed on p0deje/Maccy#206, PR p0deje/Maccy#1542 open). Two things cannot be patched in: a modal UI where keys are commands until `/`, `?` or `:` starts typing (Maccy's search field always has focus), and a store that is a plain folder. Time filters do not exist upstream either. Rules out: a Maccy fork, which would carry its model and its store.

## 2026-10-30 Stack: Swift, AppKit menu bar agent, Apple frameworks only, scommon

Why: same reasons as the rest of the family; the app is a status item, a pasteboard poll, a Carbon hotkey and one panel, all direct in AppKit. `LSUIElement`, no Dock icon, no main window. scommon gives the key grammar (`Key`, `Keymap`, `KeyMatcher`) and the config layer (`ConfigPaths`, `KeyValueSettings`). macOS 26 minimum. Rules out: SwiftUI `App`, `MenuBarExtra`, third-party hotkey or clipboard packages.

## 2026-10-30 The history is a folder of files

Why: "the folder is the document". `~/Library/Application Support/sPaste/history/`, mode 0700: one file per item named `<yyyy-MM-dd-HHmmss>-<nnn>.<ext>` (`.txt` plus an optional `.rtf`, `.png` or `.tiff`, `.files` with one path per line) and an `index` text file with one line per item, `<id> <app> <digest> [pin]`. The name carries the time and the extension the type, so the index can be rebuilt from the folder. Deleting or pruning removes the files, so nothing evicted stays readable (Maccy #1603). History is data, not settings, so it does not live in `~/.config/spaste/` and is never part of a config export. Rules out: SQLite, SwiftData, Core Data, a single archive file.

## 2026-10-30 Enter copies; pasting is opt-in

Why: sending Cmd+V needs Accessibility, and an ad hoc signed download loses that grant on every update. Copy-back needs no permission. `paste_on_enter yes` turns on the paste. Rules out: Accessibility as a requirement to use the app.

## 2026-10-30 Filters narrow the list; search moves the selection

Why: two different questions. A filter (`ft fi ff fa`, `:type`, `:since`, `:until`, or `type:` `since:` `until:` tokens) answers "show me only these"; a search answers "take me to the one with this text" as in vim: `/` scans from the newest item down, `?` from the oldest up, the selection moves while typing, `n` repeats in the same direction and `N` in the other, wrapping. Enter ends the search, Esc returns to where it started. Filter tokens typed in a search line are applied as filters. Rules out: Maccy's search-as-filter list, which hides the context around a match.

## 2026-10-30 Default hotkey Shift+Cmd+C

Why: Sam's choice and Maccy's default, so muscle memory carries over. It takes the keys from Finder's Go > Computer and Chrome DevTools' inspect while sPaste runs. Registered with Carbon `RegisterEventHotKey`, which needs no permission. Written `hotkey shift-cmd-c` in the config: the hotkey keeps `shift-` on a letter, unlike keymap keys where case carries shift. Rules out: running sPaste and Maccy with the same hotkey (the PoC showed both registrations succeed, so which app gets the key is not defined).

## 2026-10-30 Skipped pasteboard items

Why: password managers mark secrets. Items carrying `org.nspasteboard.ConcealedType`, `org.nspasteboard.TransientType` or `org.nspasteboard.AutoGeneratedType` are never read past their type list, nor are types named by `ignore_type` or copies made while an app named by `ignore_app` is frontmost. Images over `max_image_mb` are skipped rather than stored. Rules out: storing secrets and redacting them later.

## 2026-10-30 Settings window over the config file

Why: Sam asked for friendly settings and config export like sView and sNotate. The file stays the truth: each control writes its line through `ConfigPaths.persist`, the repeating keys (`ignore_app`, `ignore_type`) are rewritten as a block in the place of their first line, and the app reloads at once. Export and import use scommon's `ConfigArchive` with config and keymap only; the history is data and never travels with the config. Rules out: UserDefaults, a second settings store, editing keys in the window (they stay in `keymap`).

## 2026-10-30 Brand: grape, a clipboard around the s

Why: Sam asked for a purple that reads calm and trustworthy. Violet is sWalk's (`#8b5cf6` to `#6d28d9`), so sPaste takes grape, `#9b59b6` to `#6c3483`, a muted red-violet that stays apart from sWalk and sView in the Dock. The accent is a thin white clipboard frame with its clip, of the weight of sView's brackets, around the shared `s`. The menu bar keeps the white-stroke `list.clipboard` symbol, which Sam likes and which takes the menu bar tint as a template image. Rules out: sWalk's violet, a second glyph, a coloured menu bar icon.
